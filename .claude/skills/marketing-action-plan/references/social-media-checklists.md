# Social media platform audit checklists

Exact per-platform audit checklists from Purple Giraffe's master MAP
template. Use these verbatim when auditing each platform in the Social
media marketing → Platform review section. Audit only — describe current
state, don't introduce strategy here (see `section-playbook.md`).

## Facebook

- Ensure set up as a business page
- Review profile imagery (cover image and profile picture — should be logo
  for ease of searchability and recognisability)
- Facebook handle (listed as @xxxx under page name if activated)
- Page button set to relevant call to action (e.g. Learn more, Shop now)
- "Our story" (cover image updated? copy consistent with website content
  and call-to-action/contact details available?)
- Content (frequency of publication, quality, relevance)
- Use of Stories (current usage, based on client conversation and profile
  evidence)
- Services/product tab (consistent with website content?)
- Reviews (active? how many, current rating?)
- Shop and offers (current use)
- Events (current/past use)
- About us (up to date and relevant?)
- Messaging (autoresponder activated? current response rate if listed?)
- Pages liked by this page (review and update)
- Linked to Instagram account?
- Paid social media campaigns (activity, status, performance)
- Current likes/followers
- Reels — are they being used?

Only include data screenshots (audience demographics, usage patterns,
popular content, past campaign results) if they add real value.

## Instagram

- Set up as a public business profile?
- Profile (profile picture, name, username, website link, bio)
- Instagram handle (listed as @xxxx under page name if activated)
- Content (frequency, quality, relevance)
- Story highlights (listed on profile, relevant titles, branded cover
  images — current usage based on client conversation and profile evidence)
- Link tree activated? (if relevant)
- Pages followed (review)
- Linked to Facebook business page?
- Current likes/followers
- Reels — are they being used?

## X (Twitter)

- Profile imagery (cover image and profile picture — should be logo)
- Profile (name, username, website, location, bio/business information)
- Content (frequency, quality, relevance)
- Pages followed by this account (review)
- Page publication status/privacy settings
- Current likes/followers

## LinkedIn

- Ensure set up as a business page
- Profile imagery (cover image and profile picture — should be logo)
- LinkedIn page name
- Content (frequency, quality, relevance)
- Website button available?
- Tagline updated?
- Community hashtags highlighted on profile?

## YouTube

- Profile imagery (cover image and profile picture — should be logo)
- About section (relevant and up to date, located near cover image)
- Accounts subscribed to and videos liked by the account (review)
- Current likes/followers/subscribers

## Other platforms (add as relevant)

Threads, Pinterest, TikTok, and any other platform the client is active on
— apply the same general pattern (profile setup, imagery, handle, content
frequency/quality/relevance, follower count, linkage to other owned
profiles) even without a pre-built checklist here.
